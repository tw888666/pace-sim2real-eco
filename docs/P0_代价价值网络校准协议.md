> 状态：基础代码已实现并通过 CPU（中央处理器）测试，等待 GPU（图形处理器）轨迹采集。  
> 冻结 actor（策略网络）：`model_3097.pt`。

## 1. 目的

验证有限 20 秒回合中，cost critic（代价价值网络）是否需要归一化剩余时间，排除网络参数量、仿真随机性、动作采样和数据划分带来的混杂因素。

P0 期间不更新拉格朗日乘子，不启动正式预算实验。

## 2. 指标定义

对每个有效时间步使用完整回合的真实剩余累计代价：

\[
G_t^C=\sum_{u=t}^{T-1}c_u.
\]

失败屏障只在终止步计入一次，不使用 GAE（广义优势估计）或 rollout（采样段）自举目标替代。

残差固定定义为 \(e=\hat G-G\)：

- signed bias（有符号偏差）：\(\mathbb E[e]\)；
- absolute mean bias（均值偏差绝对值）：\(|\mathbb E[e]|\)；
- MAE（平均绝对误差）：\(\mathbb E[|e|]\)；
- RMSE（均方根误差）：\(\sqrt{\mathbb E[e^2]}\)。

同时报告：

- 初态全部指标；
- pooled EV（全部有效时间步合并的解释方差）；
- 全时间步 pooled RMSE；
- 每回合等权 RMSE；
- 按剩余时间分箱的 RMSE；
- 成功与失败回合分别统计；
- 目标与预测的均值和标准差。

## 3. 配对对照

冻结 `model_3097.pt`，只运行一次仿真并保存 episode-major（按回合组织）的数据。按完整回合划分训练集和留出集，不能将同一回合的时间步拆到两侧。

三组对照：

1. `zero_time`：48 维状态 + 恒定零；
2. `real_time`：48 维状态 + 真实归一化剩余时间；
3. `time_only`：只使用剩余时间的线性基线。

前两组都使用 49 输入、`[256, 256, 128]` 网络、相同训练批次顺序和配对初始化种子 `0,1,2`。`time_only` 是解释性参照，不是必须显著击败的硬门槛。

## 4. 执行顺序

### 4.1 一次性采集冻结策略数据

此命令使用物理 GPU 0 的 A100；生成数据，不更新任何模型权重：

```bash
conda activate env_isaaclab
cd /home/xy.chen/tw/isaaclab_ws/pace-sim2real

CUDA_VISIBLE_DEVICES=0 python scripts/pace/collect_cost_critic_dataset.py \
  --checkpoint logs/rsl_rl/pace_eco_anymal_d_flat/2026-07-24_23-22-05_overnight_eta005_seed42/model_3097.pt \
  --output data/pace_eco/cost_critic_model3097_seed24680.pt \
  --budget_j 26072.25390625 \
  --num_envs 256 \
  --seed 24680 \
  --headless \
  --device cuda:0
```

数据包含同一批策略观察、剩余时间、每步增广代价、有效掩码、成功标志和物理焦耳数，并记录 actor checkpoint（策略检查点）的 SHA-256。

### 4.2 运行配对 critic 对照

该步骤不启动 Isaac Sim，但会训练六个小型 critic；GPU 运行仍由用户手动启动：

```bash
CUDA_VISIBLE_DEVICES=0 python scripts/pace/compare_cost_critics.py \
  --dataset data/pace_eco/cost_critic_model3097_seed24680.pt \
  --output_dir logs/cost_critic_comparison/model3097_seed24680 \
  --device cuda:0 \
  --critic_seeds 0 1 2 \
  --split_seed 13579 \
  --validation_fraction 0.2 \
  --epochs 30 \
  --batch_size 4096 \
  --learning_rate 0.001
```

结果写入 `comparison.json`，每个 critic 保存独立模型和初始/最终哈希。选择 `real_time_seed_<n>.pt` 时，以留出集结果为依据，不能按训练误差选择。

### 4.3 critic-only 预热

只有配对对照支持时间假设后才执行。将 `<n>` 换成选定初始化种子：

```bash
CUDA_VISIBLE_DEVICES=0 python scripts/rsl_rl/train.py \
  --task Isaac-Pace-Eco-Anymal-D-Flat-v0 \
  --num_envs 2048 \
  --max_iterations 100 \
  --resume \
  --load_run 2026-07-24_23-22-05_overnight_eta005_seed42 \
  --checkpoint model_3097.pt \
  --reset_cost_critic_on_resume \
  --critic_only \
  --cost_critic_warmstart logs/cost_critic_comparison/model3097_seed24680/real_time_seed_<n>.pt \
  --energy_budget_j 26072.25390625 \
  --seed 42 \
  --run_name p0_cost_critic_preheat_seed42 \
  --headless \
  --device cuda:0 \
  agent.num_steps_per_env=64
```

训练开始和结束时必须输出完全相同的 actor、动作标准差和 reward critic（奖励价值网络）哈希，否则本次预热无效。

### 4.4 解冻 actor、固定乘子

预热通过后，从其最终 checkpoint 恢复，不再传入 `--critic_only` 或 `--reset_cost_critic_on_resume`。固定 \(\lambda=0\) 再训练 100 次更新，用于检验策略分布变化时 cost critic 能否保持校准。具体 checkpoint 名称在预热日志生成后填写。

### 4.5 两次独立完整回合评估

对同一个冻结 checkpoint 建立连续两个 cycle，分别使用不同评估 seed。新版 `dual_eval.py` 输出 schema v2（结果模式第 2 版）完整轨迹指标。

进入乘子更新阶段的暂定门槛：

- 两个结果的 checkpoint SHA-256 完全相同；
- 两个评估 seed 不同；
- 两次初态 absolute mean bias 都不超过 0.05；
- 两次 pooled trajectory EV 都不低于 0.5；
- RMSE 门槛在查看正式对照结果前固定；
- 所有指标和模型权重均为有限值。

## 5. cost advantage 标准化

本地 ECO 源码会在完整 rollout 上标准化 cost advantage（代价优势）。主方法因此固定为：

```text
normalize_cost_advantage = true
normalize_advantage_per_mini_batch = false
```

即只做一次全 rollout 标准化。实现提供 `normalize_cost_advantage=false` 作为消融选项；正式恢复 \(\lambda\) 更新前必须冻结该选择并记录在配置中。

## 6. 当前停止条件

在以下任一情况发生时，不继续联合训练或乘子更新：

- `real_time` 在三个配对种子上明显劣于 `zero_time`；
- actor/reward critic 哈希在 critic-only 阶段变化；
- v2 完整轨迹指标出现 NaN 或无穷；
- 两次独立评估未通过门槛；
- checkpoint、数据集或评估结果的 SHA-256 不匹配。
