# P0 代价价值网络校准协议

> 状态：时间对照、离线预热、固定乘子解冻训练和两次独立评估均已完成；P0 因在线绝对标定漂移仍未通过。
> 冻结 actor（策略网络）：`model_3097.pt`。  
> 开发预算：`26072.25390625 J`，仅用于 P0 诊断，不是正式论文预算。

## 1. 目的

验证有限 20 秒回合中，cost critic（代价价值网络）是否需要归一化剩余时间，并在时间假设通过后解决在线 GAE（广义优势估计）更新造成的绝对标定漂移。

P0 期间不更新拉格朗日乘子，不启动正式预算实验。

## 2. 指标定义

对每个有效时间步使用完整回合的真实剩余累计代价：

\[
G_t^C=\sum_{u=t}^{T-1}c_u.
\]

失败屏障只在终止步计入一次，不使用 GAE（广义优势估计）或 rollout（采样段）自举目标替代。

残差固定定义为 \(e=\hat G-G\)：

- signed bias（有符号偏差）：\(\mathbb E[e]\)；
- absolute mean bias（均值偏差绝对值）：\(|\mathbb E[e]|\)；
- MAE（平均绝对误差）：\(\mathbb E[|e|]\)；
- RMSE（均方根误差）：\(\sqrt{\mathbb E[e^2]}\)。

同时报告：

- 初态全部指标；
- pooled EV（全部有效时间步合并的解释方差）；
- 全时间步 pooled RMSE；
- 每回合等权 RMSE；
- 按剩余时间分箱的 RMSE；
- 成功与失败回合分别统计；
- 目标与预测的均值和标准差。

## 3. 配对对照

冻结 `model_3097.pt`，只运行一次仿真并保存 episode-major（按回合组织）的数据。按完整回合划分训练集和留出集，不能将同一回合的时间步拆到两侧。

三组对照：

1. `zero_time`：48 维状态 + 恒定零；
2. `real_time`：48 维状态 + 真实归一化剩余时间；
3. `time_only`：只使用剩余时间的线性基线。

前两组都使用 49 输入、`[256, 256, 128]` 网络、相同训练批次顺序和配对初始化种子 `0,1,2`。`time_only` 是解释性参照，不是必须显著击败的硬门槛。

### 4.3 critic-only 预热

只有配对对照支持时间假设后才执行。将 `<n>` 换成选定初始化种子：

### 4.4 解冻 actor、固定乘子

预热通过后，从其最终 checkpoint 恢复，不再传入 `--critic_only` 或 `--reset_cost_critic_on_resume`。固定 \(\lambda=0\) 再训练 100 次更新，用于检验策略分布变化时 cost critic 能否保持校准。具体 checkpoint 名称在预热日志生成后填写。

### 4.5 两次独立完整回合评估

对同一个冻结 checkpoint 建立连续两个 cycle，分别使用不同评估 seed。新版 `dual_eval.py` 输出 schema v2（结果模式第 2 版）完整轨迹指标。

进入乘子更新阶段的暂定门槛：

- 两个结果的 checkpoint SHA-256 完全相同；
- 两个评估 seed 不同；
- 两次初态 absolute mean bias 都不超过 0.05；
- 两次 pooled trajectory EV 都不低于 0.5；
- RMSE 门槛在查看正式对照结果前固定；
- 所有指标和模型权重均为有限值。

## 5. cost advantage 标准化

本地 ECO 源码会在完整 rollout 上标准化 cost advantage（代价优势）。主方法因此固定为：

```text
normalize_cost_advantage = true
normalize_advantage_per_mini_batch = false
```

即只做一次全 rollout 标准化。实现提供 `normalize_cost_advantage=false` 作为消融选项；正式恢复 \(\lambda\) 更新前必须冻结该选择并记录在配置中。

## 6. 当前停止条件

在以下任一情况发生时，不继续联合训练或乘子更新：

- `real_time` 在三个配对种子上明显劣于 `zero_time`；
- actor/reward critic 哈希在 critic-only 阶段变化；
- v2 完整轨迹指标出现 NaN 或无穷；
- 两次独立评估未通过门槛；
- checkpoint、数据集或评估结果的 SHA-256 不匹配。

## 7. P0.2 终端边界监督对照

### 7.1 已确认结果

49 维真实时间组相对恒定零时间列将全轨迹 RMSE 从约 `0.26242` 降至 `0.01083`，时间假设已经通过。随后固定 \(\lambda=0\) 解冻训练得到的 `model_3295.pt` 在两个独立 seed 上表现高度一致：

| 指标 | seed 24680 | seed 97531 | 门槛 |
| --- | ---: | ---: | ---: |
| 初态 absolute mean bias | 0.15454 | 0.15536 | ≤0.05 |
| 初态 RMSE | 0.15460 | 0.15626 | ≤0.05 |
| pooled 全轨迹 EV | 0.94563 | 0.94526 | ≥0.5 |
| 回合等权 RMSE | 0.07892 | 0.08313 | ≤0.05 |

因此 P0 仍未通过。当前应将“同步回合相位、\(\gamma_C=1\) 和短 rollout 自举使终端锚点传播不足”称为高可信机制，不能称为唯一证明的根因。

### 7.2 边界损失

第一修复方案保持 cost critic 网络和 actor 观察不变，在每个 cost critic mini-batch（小批次）中复制观察，将复制数据的 `cost_time` 置零，并加入：

\[
\mathcal L_{\mathrm{boundary}}
=
\mathbb E_s\left[V_C(s,t_{\mathrm{remain}}=0)^2\right].
\]

总的 cost critic loss 为：

\[
\mathcal L_C
=
\mathcal L_{\mathrm{GAE}}
+\beta_0\mathcal L_{\mathrm{boundary}}.
\]

基线固定 \(\beta_0=0\)，第一组边界实验固定 \(\beta_0=1\)。该损失不进入 actor loss，不改变 actor、reward critic 或 PACE 物理能耗，也不更新 \(\lambda\)。日志新增 `Loss/cost_boundary`、`Loss/cost_boundary_abs` 和 `Loss/cost_terminal_boundary_coef`。

### 7.3 冻结 actor 的边界实验

从与原 critic-only 基线完全相同的 `model_3097.pt`、离线 seed 0 warmstart 和训练 seed 42 开始，只新增边界系数：

```bash
conda activate env_isaaclab
cd /home/xy.chen/tw/isaaclab_ws/pace-sim2real
unset LD_LIBRARY_PATH

CUDA_VISIBLE_DEVICES=0 python scripts/rsl_rl/train.py \
  --task Isaac-Pace-Eco-Anymal-D-Flat-v0 \
  --num_envs 2048 \
  --max_iterations 100 \
  --resume \
  --load_run 2026-07-24_23-22-05_overnight_eta005_seed42 \
  --checkpoint model_3097.pt \
  --reset_cost_critic_on_resume \
  --critic_only \
  --cost_critic_warmstart logs/cost_critic_comparison/model3097_seed24680/real_time_seed_0.pt \
  --energy_budget_j 26072.25390625 \
  --seed 42 \
  --run_name p0_boundary_b1_preheat_seed42 \
  --headless \
  --device cuda:0 \
  agent.num_steps_per_env=64 \
  agent.algorithm.cost_terminal_boundary_coef=1.0
```

验收时将该 checkpoint 与已有无边界基线 `2026-07-26_15-19-29_p0_cost_critic_preheat_seed42/model_3196.pt` 使用相同评估 seed 比较。两者 actor 哈希必须相同。边界实验首先要求 `cost_boundary_abs` 明显趋近零，并检查初态 bias、完整轨迹 RMSE 和按剩余时间分箱 RMSE是否改善。

若边界损失不能解决漂移，第二方案才使用当前或最近冻结策略新采集的完整回合 Monte Carlo（蒙特卡洛）辅助数据；不得长期回放 `model_3097.pt` 的旧轨迹作为后续策略的监督目标。

从含边界系数的 checkpoint 恢复训练时，必须再次显式传入相同的 `agent.algorithm.cost_terminal_boundary_coef=1.0`。训练入口会拒绝系数不一致的分段恢复，避免静默改变实验方法。评估脚本只做推理，不受该训练保护限制。

### 7.4 新鲜 MC 与初态锚点的最终结果

边界损失在冻结 actor 对照中显著改善全轨迹指标，但固定 \(\lambda=0\) 解冻 100 次更新后初态仍有约 `-0.052` 偏差。因此对当前 `model_3295.pt` 采集 256 个新鲜完整回合，使用无折扣 return-to-go 辅助监督。

均匀 MC replay 已将全轨迹 EV 提升到约 `0.999`，但 reset 初态仅占全部 transition 的约 `0.1%`，初态偏差仍约 `+0.060`。最终损失在均匀 MC 项之外显式加入：

\[
\mathcal L_{\mathrm{MC-init}}
=
\mathbb E_{s_0}\left[
\left(V_C(s_0,1)-G_C(s_0)\right)^2
\right].
\]

最终 P0 cost critic 损失为：

\[
\mathcal L_C
=
\mathcal L_{\mathrm{GAE}}
+\mathcal L_{\mathrm{boundary}}
+\mathcal L_{\mathrm{MC}}
+\mathcal L_{\mathrm{MC-init}}.
\]

本轮四项系数均为 1。MC 数据必须来自当前冻结 actor checkpoint，训练入口通过 SHA-256 和预算值强制校验；MC 项仅允许 critic-only 阶段启用。

最终 checkpoint `2026-07-26_17-46-42_p0_boundary_b1_mc1_initial1_calib_seed42/model_3319.pt` 在 seed 24680/97531 上分别得到：初态绝对 bias `0.00063/0.00005`、初态 RMSE `0.00478/0.01646`、pooled 全轨迹 EV `0.99962/0.99940`、回合等权 RMSE `0.00563/0.01750`。门槛脚本返回 `PASS`，因此 P0 完成。
