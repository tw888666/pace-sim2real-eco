# P1 B90 开发选择与停止协议

## 1. 适用范围

本协议从 2026-07-26 起用于 P1 开发实验。它在已经观察到第一轮学习率结果后冻结，因此不能称为预注册协议；此前结果只作探索性开发证据。

当前结论固定为：

- P0 代价价值网络校准正式通过；
- B90 尚未满足；
- `model_3295.pt` 给出的 B100/B90/B80 仅为开发候选预算；
- \(\eta_\lambda=0.05\) 只是暂定开发值，不是已选最优值；
- 暂不启动 B80 和正式三训练种子实验。

## 2. 指标名称

以下指标不得混用：

- 成功回合平均相对超预算幅度：

  \[
  \frac{\overline E_{\mathrm{success}}}{B}-1.
  \]

  这是有符号均值，负值表示平均低于预算。

- 回合能量违反比例：所有评估回合中 \(E_i>B\) 的比例。
- 成功条件能量违反比例：成功回合中 \(E_i>B\) 的比例。
- 联合可行率：同时满足“回合成功”和 \(E_i\le B\) 的回合比例。
- 平均增广代价：包含失败屏障的训练约束均值；屏障不计入物理焦耳数。

每个新 dual-eval（对偶评估）结果使用 schema v3，同时记录上述指标。旧 schema v1/v2 保持只读兼容；既有完整回合数据的补算结果单独保存在 `logs/p1_b90_metric_backfill/`，不覆盖原始结果。

## 3. 一个开发周期的定义

一个周期固定包含：

1. 2048 个环境、64 步 rollout（采样段）、100 次 PPO 更新；
2. 冻结 actor（策略网络）checkpoint；
3. 用 seed 13579 采集 256 个新鲜完整回合，校准该策略对应的 cost critic（代价价值网络）；
4. 用 seed 24680 进行主 dual-eval；
5. 用 seed 97531 进行独立审计评估；
6. 两次 P0 门槛都通过后，只允许主评估结果幂等更新一次 \(\lambda\)。

任一 critic 门槛失败，该周期不得用于学习率选择或更新 \(\lambda\)。

## 4. 乘子学习率的等周期比较

候选固定为：

\[
\eta_\lambda\in\{0.01,0.05,0.10\}.
\]

三者都从相同的 B90 校准 checkpoint 和各自 cycle 0 状态开始，先补齐到 3 个完整周期。当前进度为：

- \(0.01\)：探索性 actor cycle 1 已完成，但正式校准、双 seed 评估和状态应用尚未完成；
- \(0.05\)：cycle 1、2 已完成；还需 cycle 3；
- \(0.10\)：探索性 actor cycle 1 已完成，但正式校准、双 seed 评估和状态应用尚未完成。

cycle 3 后按以下顺序选择：

1. 最近两个周期任一主评估成功率低于 0.98，或任一双 seed critic 门槛失败，则淘汰；
2. 在剩余候选中，比较 cycle 2、3 主评估平均增广代价的均值，较低者优先；
3. 若差值不超过 0.0025，选择较小的 \(\eta_\lambda\)；
4. 若全部淘汰，停止 P1，不临时更改门槛选出“最好”候选。

## 5. 选定学习率后的通过与停止规则

选定分支至少运行 5 个周期，最多运行 10 个周期。

### B90 通过

连续 3 个主评估周期同时满足：

- 平均增广代价不高于 1.0；
- 成功率不低于 0.98；
- 两个评估 seed 的 critic 门槛均通过。

这表示期望增广代价约束在开发协议下通过。回合能量违反比例和联合可行率仍需单独报告，不能由均值通过推导。

### 成功率停止

出现任一情况立即停止该分支：

- 单周期主评估成功率低于 0.95；
- 连续 2 个主评估周期成功率低于 0.98。

### 平台停止

至少已有 6 个周期后，比较最近 3 周期与此前 3 周期的“成功回合平均相对超预算幅度”均值。若改善小于 0.0025，且最近 3 周期仍全部高于 0，则判为平台并停止。

平台停止只能表述为“该算法配置在给定开发周期内未满足 B90”，不能证明预算不可行。

### 上限停止

达到 10 个周期仍未通过即停止。即使 \(\lambda=100\) 仍超预算，也只能报告 PPO-Lagrangian（近端策略优化—拉格朗日）未达到该预算。

## 6. 每周期必须归档的量

- checkpoint 路径和 SHA-256；
- 训练 seed、采集 seed、两个评估 seed；
- \(\lambda\)、\(\eta_\lambda\) 和 cycle ID；
- 平均增广代价；
- 所有回合平均物理能量；
- 成功回合平均物理能量及其相对超预算幅度；
- 回合能量违反比例；
- 成功条件能量违反比例；
- 联合可行率；
- 成功率；
- P0 的 bias、RMSE 和全轨迹 EV 指标。

## 7. 正式预算重标定

当前开发候选预算来源于继承旧占位约束训练谱系的 `model_3295.pt`，不能作为论文正式预算。

正式预算必须使用新注册任务 `Isaac-Pace-Eco-Anymal-D-Flat-Unconstrained-v0` 从随机初始化训练标准 PPO：

- 不加载任何旧 checkpoint；
- actor loss 中没有 PACE 能耗项、cost advantage（代价优势）或 \(\lambda\)；
- 使用相同 ANYmal-D 环境、奖励、网络规模、2048 环境和 64 步 rollout；
- 参考训练 seed 固定为 42，上限 3000 次更新；
- 冻结最终 checkpoint，用 seed 24680 和 97531 各评估 256 个完整回合；
- 两次成功率均须不低于 0.98；
- B100 定义为两个评估集合中全部成功回合物理能量的算术均值，B90/B80 分别为其 90%/80%。

这里从中位数改为算术均值，是因为约束目标是期望代价；该变化作为显式协议修订记录。正式预算生成后，旧开发 dual state 不迁移，B90 从 cycle 0 重新开始。
